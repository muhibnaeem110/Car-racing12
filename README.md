# NEON RUSH — Street Racing
A mobile-friendly arcade racing game website.

## Play
Open `index.html` in a browser, or enable GitHub Pages for the repository to publish it.

## Controls
- LEFT / RIGHT: steer
- ACCELERATE / BRAKE: adjust speed
- DRIFT: turn on drift effects
- On touch screens, you can also swipe across the track.

Built with HTML, CSS, and JavaScript in one file.
